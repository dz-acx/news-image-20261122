A single-file Python program that renders a 1024x1024 infographic newspaper front page documenting the top world news events of Sunday, 22 November 2026 — featuring COP31 climate talks running into a second day of overtime in Antalya, Iran striking a site in Bahrain, and Mexico capturing FBI top-10 fugitive "El Chapo Isidro" in Sinaloa, alongside a "By the Numbers" data strip, a dot-matrix world map with numbered markers, and 11 concise global dispatches. The graphic is drawn deterministically using purely the Python standard library (`zlib` and `struct`) with a 4x supersampled anti-aliased canvas and procedural vector stroke fonts, completely free of external dependencies.

## Run it

```bash
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```
